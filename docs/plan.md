# Project Plan: album-rating-log

## Purpose
This application allows users to track and rate albums they have listened to. For example, a music enthusiest may find it hard to keep track of every album they have listened to and what they thought of it. This will allow them to quickly insert information about an album then quickly retrieve it when needed.

## Features

These are some of the features that this application will include
- Add/Remove Albums
- Rating albums 1/5
- Saving/Loading Albums via JSON
- Filtering

## Storage

The application will utilise JSON so store and load albums and their ratings
